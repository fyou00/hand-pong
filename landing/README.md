# Palm Pong — landing page

Implementasi statis dari frame FigCraft **Palm Pong · Arcade Landing**.
HTML/CSS/JavaScript tanpa build, dependensi, atau akses webcam. Tombol Main
sekarang membuka panduan game desktop; arena adalah ilustrasi.

Dari root repo:

```bash
python3 -m http.server 8000 --directory landing
```

Buka http://localhost:8000. Bisa juga membuka `index.html` langsung; penyalinan
clipboard bergantung dukungan browser dan secure context. Escape menutup dialog.
Tidak perlu menjalankan Python game untuk melihat landing page.
