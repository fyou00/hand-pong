# Palm Pong — landing page

Implementasi statis dari frame FigCraft **Palm Pong · Arcade Landing**.
HTML/CSS/JavaScript tanpa build, dependensi, atau akses webcam. Tombol Main di desktop
mengarah ke panduan instalasi yang tetap tersedia tanpa JavaScript; arena adalah ilustrasi.

Dari root repo:

```bash
python3 -m http.server 8000 --directory landing
```

Buka http://localhost:8000. Bisa juga membuka `index.html` langsung; penyalinan
clipboard bergantung dukungan browser dan secure context. Semua navigasi utama memakai anchor HTML standar.
Tidak perlu menjalankan Python game untuk melihat landing page.
