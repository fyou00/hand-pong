Main di desktop

Mulai di desktop.

Game saat ini berjalan di komputer dengan Python 3.11 dan webcam RGB. Halaman ini tidak mengakses kamera atau menjalankan game.

  1. Unduh source, ekstrak, lalu buka terminal di folder game.
  2. Buat virtual environment dan pasang dependensi:
python3.11 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python menu.py

Perintah di atas untuk macOS/Linux. Windows: gunakan .venv\Scripts\activate. Izinkan akses kamera saat diminta.
